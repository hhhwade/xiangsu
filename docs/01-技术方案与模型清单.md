## 1. 技术选型结论

| 层 | 选型 | 理由 |
|---|---|---|
| 移动端 | **Flutter（推荐）** | 一套代码出 Android/iOS；图像预览、前后对比拖动滑块、滑杆参数等 UI 性能优于 RN 桥接；打包链路（Gradle/Xcode）成熟，签名流程清晰 |
| 后端 API | **FastAPI** | 异步、自带 OpenAPI 文档、与 Python 推理生态无缝 |
| 任务队列 | **Celery + Redis** | 大图推理异步化，前端轮询 `/api/task/{id}`；Celery 支持超时/重试/并发控制 |
| 推理框架 | PyTorch + diffusers（SD 路线）/ ONNX Runtime（轻量路线） | 模型按需加载、LRU 显存管理 |
| 人体/人脸分析 | MediaPipe（face mesh、selfie segmentation）+ RTMPose（人体关键点，可选） | 关键许可均为 Apache 2.0，**可商用**（详见 §5 模型清单） |
| 存储 | **MinIO**（自建）/ 阿里 OSS（生产可选） | 原图与结果图走对象存储 + 预签名 URL |
| 反向/网关 | docker-compose: nginx + server + worker + redis + minio | 一键部署 |
| 打包 | Android: Gradle 出 APK/AAB；iOS: Xcode 出 IPA（脚本 + 手册） | 见《部署与打包手册》 |

## 3. 功能一：图片转 Q 版像素可爱风 — 实现路径

**主路线（SD）**：SD1.5 + 「像素风/卡哇伊」LoRA，img2img 风格迁移
- 人脸/主体检测（MediaPipe face detection）→ 构造主体 mask
- img2img：denoise_strength = Q 化强度；像素颗粒度 = 前置下采样/块大小（马赛克→超分还原）+ LoRA 像素权重双控制
- 保留背景开关：mask 反选，仅对主体做重绘；或人后景分离后分别处理再合成
- IP-Adapter（参考图特征注入，保 identity），权重可调 = 保真度/萌度权衡

**轻量路线**：AnimeGANv2（ONNX，仅 8MB 权重，4GB 显存甚至 CPU 可用）+ OpenCV 像素化滤镜组合。效果略弱但成本极低，建议两者都实现、按 GPU 档位切换。

## 4. 功能二：AI 自动美化 P 图 — 实现路径

| 子功能 | 技术路径 | 备注 |
|---|---|---|
| 美白 | HSV/Lab 空间肤色区间（YCbCr 掩码）提亮 + 直方图保护 | 不过曝：亮度增益 soft-clamp |
| 磨皮 | 高频金额去除：FaceMesh ROI 内导向滤波/双边滤波 + 边缘保护叠加层 | 保留纹理参数=高频回混比例 |
| 瘦脸/大眼/唇形 | MediaPipe 478 点 face mesh → 局部 mesh warp（MLS 移动最小二乘形变） | 不生成新像素，安全可控 |
| 瘦身/瘦腿 | RTMPose 人体关键点 + MediaPipe/移动解析分割 → 部位 warp + 接缝处泊松融合修复 | 背景直线区做自适应约束 |
| 美发 | 发区分割（U²‑Net/MODNet→SAM refine）→ Lab 通道色彩迁移 + 高光增强 | 参数：目标发色/光泽度 |
| 补发 | 发区分割出发际线 mask → SD inpainting 填充生成 | 需 SD 路线在线；轻量模式降级为告示 |
| 整体精修（可选） | GFPGAN 面部精修过一遍 | 可选开关 |
| 「学习 P 图师」 | training/retouch_finetune：采集「原图—修图师成品」配对数据，训练风格 LoRA 或用 ControlNet/img2img 微调，推理时以低强度叠加统一精修质感 | 数据建议：自建 200–1000 对（爬取需授权）；数据集格式 JSON 配对清单 |

## 5. 模型清单（核心交付物，含许可与外存）

| # | 模型 | 用途 | 获取方式 | 显存 | 许可/可否商用 |
|---|---|---|---|---|---|
| 1 | stable-diffusion-v1-5 (runwayml) | img2img 风格迁移 | HuggingFace 注册下载 | ~4GB(fp16) | CreativeML OpenRAIL-M，**可商用**（需遵守使用限制条款） |
| 2 | stable-diffusion-v1-5-inpainting | 补发 inpainting | HuggingFace | ~4GB(fp16) | 同上，可商用 |
| 3 | 像素风/卡哇伊 LoRA（Civitai 现成 or training/ 自训） | Q 版风格 | Civitai 下载或本工程训练脚本 | 与底模共享 | ⚠️ Civitai 模型许可逐项确认；自训 LoRA 归自有 |
| 4 | IP-Adapter (sd1.5, h94) | 身份保真 | HuggingFace | +1GB | Apache 2.0，可商用 |
| 5 | ControlNet canny/depth (lllyasviel) | 结构控制（可选增强） | HuggingFace | +1.5GB/个 | Apache 2.0，可商用 |
| 6 | AnimeGANv2 (onnx) | 轻量风格迁移备选 | GitHub TachibanaYoshino/匿名模型库 | <1GB | MIT/Apache 2.0（AnimeGANv2: MIT），可商用 |
| 7 | MediaPipe Face Mesh + Face Detection + Selfie Segmentation | 关键点/人像分割 | pip mediapipe 内置 | 共享 CPU | Apache 2.0，可商用 |
| 8 | RTMPose (mmpose) | 人体关键点（瘦身瘦腿） | OpenMMLab 模型库 | ~0.5GB | Apache 2.0，可商用 |
| 9 | U²‑Net human_seg（及可选 MODNet/SAM-B 精修发区） | 发区/人体分割 | GitHub | <1GB | U²‑Net: Apache 2.0 可商用；SAM: Apache 2.0 可商用；⚠️ MODNet 自定义许可需邮件确认 |
| 10 | GFPGAN v1.4 | 面部精修/修复 | GitHub TencentARC | ~1.5GB | Apache 2.0，可商用 |
| ⚠️ 不采用 | CodeFormer / InsightFace 预训练 / SCHP | — | — | — | 均为**非商用/研究许可**，故本工程避让，特此标注 |

**GPU 档位建议**：
- 完整：≥12–16GB 显存（T4 16G / RTX 3060 12G+），CUDA ≥ 11.8，可跑全部功能；
- 标准：8GB，SD fp16 + 轻量模型，补发精修降并发；
- 无 GPU：CPU mock/AnimeGAN 轻量模式（仅功能一轻量版 + 经典美颜可用，文档如实标注降级清单）。

## 6. API 设计（v1）

```
POST /api/qstyle      {image|url, pixel_size, strength, keep_bg, mode:auto|sd|lite} → {task_id}
POST /api/beautify    {image|url, ops:{whiten,smooth,hair_color,hair_fill,slim_face,slim_body,slim_leg,big_eye,lip_brow,refine}, levels:{...}} → {task_id}
GET  /api/task/{id}   → {status: queued|running|done|failed, progress, result_url, original_url, error}
GET  /api/health      → {gpu, models_loaded, queue_len}
鉴权：Authorization: Bearer <token>（server .env 配置，APP 设置页可改）
校验：≤16MB，jpg/png/webp；超边长自动降采样至 2048
```
