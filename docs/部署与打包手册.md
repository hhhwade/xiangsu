# 部署与打包手册

> 覆盖：环境要求 → 模型下载 → 后端启动 → APP 双端打包全流程。
> ⚠️ 如实说明：本工程输出的是工程代码与打包链路，APK/IPA 由你在本机执行 §5 脚本产出；核心 AI 功能（Q 版 SD 生成、补发）需要后端 GPU 在线，无 GPU 时自动降级（见 §2.3）。

---

## 1. 环境要求

### 1.1 后端服务器（推理机）

| 项 | 最低 | 推荐 |
|---|---|---|
| GPU | 无（mock/lite 降级） | 8–12GB 显存（RTX 3060 12G / T4 16G） |
| 驱动 | — | NVIDIA ≥ 530，CUDA 12.1，装好 `nvidia-container-toolkit` |
| CPU/内存 | 4C8G（含 MinIO/Redis） | 8C16G |
| 磁盘 | 20G | 40G（SD 权重 ~15G） |
| 系统 | Ubuntu 20.04+ / 其他能跑 docker 的 Linux | Ubuntu 22.04 |
| Docker | 24+，docker compose v2 | 同左 |

安装 nvidia-container-toolkit（Ubuntu）：
```bash
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -s -L https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/$distribution/libnvidia-container.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
sudo apt-get update && sudo apt-get install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker && sudo systemctl restart docker
docker run --rm --gpus all nvidia/cuda:12.1.1-base-ubuntu22.04 nvidia-smi   # 验证
```

### 1.2 打包工作站（出 APK / IPA）

- **Android**（Win/Mac/Linux 均可）：JDK 17 + Android SDK + Flutter SDK stable
- **iOS**：必须 macOS + Xcode 15 + CocoaPods；签名进开发者/TF 需 Apple 开发者账号（个人免费账号只能装本机 7 天）

## 2. 后端启动（3 分钟）

```bash
cd ai-beauty-app/deploy
cp .env.example .env
# 必改：API_TOKEN（强随机）、S3_SECRET_KEY；有 SD LoRA 则填 LORA_QSTYLE_PATH
docker compose up -d --build
docker compose logs -f worker          # 首次启动自动下载 SD 权重约 15G，耐心等
curl -H "Authorization: Bearer <API_TOKEN>" http://localhost:8000/api/health
# → {"status":"ok","mode":"sd",...}   mode 字段如实告诉你当前推理等级
```

### 2.1 验证一次完整调用

```bash
curl -X POST http://localhost:8000/api/qstyle \
  -H "Authorization: Bearer <API_TOKEN>" \
  -F "file=@/path/test.jpg" \
  -F 'params={"pixel_size":12,"strength":0.55,"keep_bg":false}'
# → {"task_id":"..."}
curl -H "Authorization: Bearer ..." http://localhost:8000/api/task/<task_id>
# → done 时带 result_url（可直接浏览器打开下载）
```

### 2.2 无 GPU 服务器（CPU 演示）

把 `.env` 里 `MODE=mock`（或 `MODE=lite` + 放好 animegan_v2.onnx），
并注释 `docker-compose.yml` 里 worker 的 `deploy.resources` GPU 段（CPU 机器没有 nvidia 运行时）。
此时：
- **功能一**：走 OpenCV 卡通化（mock）/ AnimeGAN（lite）— 结果带 `mode` 标记，如实降级
- **功能二**：美白/磨皮/瘦脸/大眼/唇眉/瘦身/瘦腿/美发 全部可用（纯 CPU，MediaPipe 很快）
- **补发**：不可用，API 会在结果 `notices` 字段返回原因，APP 会展示提示 —— 这是设计行为，不是 bug

### 2.3 公网访问（APP 手机连得上）

- 云服务器：安全组开放 `8000`；前端最好套 HTTPS（Caddy 一行命令或 Nginx+Certbot），把 HTTPS 反代到 8000，再把 `deploy/.env` 不动——APP 设置页填 `https://api.你的域名`
- ⚠️ MinIO `9000/9001` 端口**不要**对公网开放（预签 URL 已走 server 内部访问）

## 3. 模型权重下载

```bash
bash scripts/download_models.sh           # 默认落 deploy/models/
```
逐项说明与手动备选：

| 项 | 必需 | 说明 |
|---|---|---|
| AnimeGANv2 onnx | 轻量模式必需 | 脚本自动拉取；失败时从 AnimeGANv2 仓库 onnx 目录手动放 |
| U²-Net parsing onnx | 可选 | 没有时美发走启发式发区（效果略降，日志注明） |
| SD1.5 + inpaint + IP-Adapter | SD 模式必需 | HF 下载（~15G），首次启动 worker 也能自动拉；网络仿问 HF 受限请设 `HF_ENDPOINT=https://hf-mirror.com` |
| Q 版像素 LoRA | 推荐 | Civitai 下载后改名 `chibi_pixel_lora.safetensors` 放 models/，**务必核对商用许可**；或自训（training/README.md） |
| MediaPipe 模型 | 必需 | pip 安装 mediapipe 后**首次调用自动下载**，无外网请预置 `~/.mediapipe` |

## 5. 打包安装包

### 5.1 Android — APK / AAB

**一次性签名准备**（2400 天有效）：
```bash
keytool -genkey -v -keystore app/android/app/key.jks \
  -keyalg RSA -keysize 2048 -validity 10000 -alias beauty
cp app/android/key.properties.example app/android/key.properties   # 填口令
```

把下面签名块**粘贴**到 `app/android/app/build.gradle.kts` 的 `android { ... }` 前面和内部（flutter create 出来的 gradle 文件基础上加）：
```kotlin
// 文件顶部配置之后
val keyPropsFile = rootProject.file("key.properties")
val keyProps = java.util.Properties().apply {
    if (keyPropsFile.exists()) load(keyPropsFile.inputStream())
}
android {
    signingConfigs {
        create("release") {
            keyAlias = keyProps["keyAlias"] as String?
            keyPassword = keyProps["keyPassword"] as String?
            storeFile = keyProps["storeFile"]?.let { file(it) }
            storePassword = keyProps["storePassword"] as String?
        }
    }
    buildTypes {
        release {
            signingConfig = signingConfigs.getByName("release")
        }
    }
}
```

**打包**：
```bash
bash scripts/build_android.sh debug   # 快速测试包（无需签名）
bash scripts/build_android.sh apk     # 发布 APK → build/app/outputs/flutter-apk/app-release.apk
bash scripts/build_android.sh aab     # Play 商店 AAB
```
安装到手机：`adb install app/build/app/outputs/flutter-apk/app-release.apk`，或直接把 .apk 发给手机点击安装。

### 5.2 iOS — IPA（macOS + Xcode）

```bash
open app/ios/Runner.xcworkspace
# Xcode：Signing & Capabilities → 勾 Automatically manage signing → 选 Team
#        Bundle Identifier 改唯一（如 com.yourname.beauty）
```
把 `app/ios/ExportOptions.plist` 里 `YOUR_TEAM_ID` 改成你的 Team ID（Apple Developer 后台 Membership 页可查），然后：
```bash
bash scripts/build_ios.sh
# 产出 app/build/ios/ipa/ai_beauty_app.ipa
```
- **装自己/同事手机**：Xcode → Window → Devices and Simulators → 拖入 .ipa（设备需在描述文件内）
- **TestFlight/上架**：Xcode Organizer → Distribute App（需要 99 美元/年付费开发者账号）

### 5.3 不能打包出来的情形（实说）

- Windows/Linux 机器打不了 iOS 包（需 macOS）
- 没有 Apple 开发者账号只能出短暂调试包
- Android 未配签名时只能打 debug 包（脚本会明确提示）

## 6. 功能 × GPU 依赖对照（用户须知）

| 功能 | CPU 可用 | GPU(SD) 模式 |
|---|---|---|
| Q 版像素风 | ✅ mock/lite 降级 | ✅ 最佳效果 |
| 美白/磨皮/瘦脸/大眼/唇色/眉形 | ✅ | ✅（纯 CV，与 GPU 无关） |
| 瘦身/瘦腿 | ✅ | ✅ |
| 美发（发色/光泽） | ✅（启发式发区） | ✅（u2net 发区更准） |
| 补发（生成填充） | ❌ 返回 notice | ✅ 必需 |
| 历史/对比/分享/保存 | ✅ | ✅ |

## 7. 常用运维

```bash
docker compose logs -f worker        # 看推理日志/OOM
docker compose restart worker        # 换了 LoRA/权重后重启
docker compose exec redis redis-cli LLEN celery   # 看排队
# 清理旧图：MinIO 控制台设 lifecycle，或 mc rm --recursive --older-than 7d local/beauty/result/
```

## 8. 故障速查

| 现象 | 处理 |
|---|---|
| health 返回 mode=mock | GPU 没被 docker 看到 → 查 nvidia-container-toolkit / `docker run --gpus all nvidia-smi` |
| worker OOM | 8G 显存请确认只有 1 个并发（compose 已设 concurrency=1）；关掉 IP-Adapter 省 1G |
| 首次任务很慢 | SD 权重在下载/首次编译 attention，看 worker 日志，属正常 |
| APP 401/403 | token 不一致 |
| APP 提交失败 413 | 图片 > MAX_IMAGE_MB，调大或让 APP 再上压缩 |
| 结果 URL 打开 403 | 预签过期（默认 7 天），重新生成即可 |
